# tumaaneena
طمأنينة منصة إسلامية رقمية تهدف إلى نشر السكينة والوعي والمعرفة الدينية في حياة المسلمين،  تتيح المنصة قراءة القرآن الكريم بالرسم العثماني، والتعرّف على الأذكار والأدعية، والاستفادة من المحتوى الإسلامي الهادف، مع الحرص على تقديم تجربة راقية تحترم القيم الإسلامية وتقرّب المستخدم من دينه، وتكون رفيقاً له في رحلته اليومية نحو الطمأنينة والإيمان
